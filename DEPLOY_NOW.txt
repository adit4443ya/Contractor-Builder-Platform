📋 DEPLOYMENT STEPS (5 minutes total)

STEP 1: SET UP SUPABASE (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
→ Go to: https://supabase.com/dashboard
→ Click "New Project"
→ Name: buildconnect (or any name)
→ Wait for setup (~ 2 minutes)

→ Go to: SQL Editor (left sidebar)
→ Copy entire content from: supabase-schema.sql
→ Paste and click "Run"

→ Go to: Settings → API
→ Copy your credentials:
   • Project URL: https://xxxxx.supabase.co
   • Anon public key
   • Service role key

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: DEPLOY TO VERCEL (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
→ Go to: https://vercel.com/new

→ Sign in with GitHub

→ Import repository: "Contractor-Builder-Platform"

→ Add Environment Variables:
   
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGci...
   NEXT_PUBLIC_URL=https://buildconnect.vercel.app
   RESEND_API_KEY=re_xxxxx (optional - for emails)

→ Click "Deploy"

→ Wait 2-3 minutes ☕

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: FINALIZE SETUP (1 minute)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
After deployment, you'll get a URL like: buildconnect-abc123.vercel.app

→ Update in Vercel:
   Settings → Environment Variables
   Edit NEXT_PUBLIC_URL with your actual URL
   Click "Redeploy"

→ Update in Supabase:
   Authentication → URL Configuration
   Site URL: https://your-app.vercel.app
   Redirect URLs: https://your-app.vercel.app/**
